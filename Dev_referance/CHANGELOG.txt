    + Cleaner foundation than BfaCore's independent codebase
    + Still get all BFA content via BfaCore manual port

[CRITICAL] TrinityCore Official is a TAG
  8.3.7/35662 is archived tag, not a branch
  Must create new branch from tag for all work
  Cannot push changes back to the tag

[CRITICAL] AGPL v3 License from BfaCore
  BfaCore uses AGPL v3 (not GPL v2)
  Any ported content requires AGPL v3 compliance
  Closed-source distribution is NOT permitted for BfaCore-derived code
  Mitigation: Only use if open-source distribution is acceptable

[HIGH] tswow Git Merge Conflicts
  tswow has 14,443 commits ahead of TrinityCore master
  Conflicts expected in custom_script_loader.cpp and overlapping scripts
  Manual conflict resolution required

[HIGH] Manual Port Required for BfaCore
  BfaCore has no shared git history with TrinityCore
  Cannot use git merge — must manually copy files and register scripts
  More effort than git merge

[MEDIUM] Transmog Implementation Conflicts
  Three different transmog implementations across sources
  Duplicate tables or conflicting logic possible
  Mitigation: Formal three-way comparison before committing

[MEDIUM] BFA Script Quality Unverified
  BfaCore dungeon/raid scripts not runtime-tested
  May contain bugs, missing phases, incorrect boss behaviors

[LOW] No Community Visibility
  Merged product starts fresh — no GitHub stars or forks
